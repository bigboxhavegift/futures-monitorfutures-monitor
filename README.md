# 期货异动监控

实时监控国内期货主力合约异动情况，自动部署到 GitHub Pages。

## 访问链接

📊 **https://bigboxhavegift.github.io/futures-monitor**

## 功能

- 每30分钟自动获取期货行情数据
- 筛选涨跌幅 ≥ 3% 的异动品种
- 生成响应式 HTML 网页
- 自动部署到 GitHub Pages

## 监控品种

- 上期所：铜、铝、锌、铅、镍、锡、黄金、白银、螺纹钢等
- 大商所：铁矿石、焦炭、焦煤、豆粕、豆油、PVC 等
- 郑商所：PTA、甲醇、棉花、白糖、纯碱、玻璃等
- 能源中心：原油、低硫燃料油、20号胶等
- 广期所：工业硅、碳酸锂

## 数据源

- AKShare / 东方财富

## 更新时间

- 交易日：09:00-15:00, 21:00-23:00（每30分钟）
